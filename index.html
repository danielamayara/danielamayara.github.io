Chatbot Zuzu

Chatbot com interface responsiva e uma API própria no Next.js. As respostas são definidas por regras e reconhecimento de palavras-chave, sem depender de um serviço externo de inteligência artificial.

Next.jsReactTypeScriptMantineCSS Modules

+ Abrir ficha da missão

O desafio foi criar um fluxo de conversa que recebe mensagens no frontend, envia os dados para /api/chat e exibe a resposta retornada pela API. O projeto serviu para praticar React, gerenciamento de estado, rotas do Next.js e construção de interfaces com Mantine.

Próxima fase ainda não desbloqueada. Quando um novo projeto estiver pronto, ele entra aqui como uma nova missão — sem misturar os detalhes do Zuzu.
