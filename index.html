Chatbot Zuzu

Chatbot desenvolvido com Next.js e React, usando respostas baseadas em palavras-chave e regras de programação. A interface foi criada com Mantine e CSS Modules, com suporte a dispositivos móveis.

Como o projeto funciona +
Interface

O usuário envia uma mensagem pelo chat. O React atualiza a conversa e mostra o carregamento da resposta.

API

A rota /api/chat recebe a mensagem e retorna uma resposta em JSON.

Regras

O backend identifica expressões conhecidas e seleciona respostas programadas. Não utiliza um modelo de IA.
