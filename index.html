VISÃO GERAL

O Chatboat Zuzu foi criado como um projeto de estudo para compreender, na prática, o funcionamento de um chatbot simples. A proposta consistiu em construir uma aplicação capaz de apresentar respostas previamente definidas, utilizando uma base de conteúdo própria e estruturas condicionais para determinar o comportamento das interações.

Detalhamento do projeto

ETAPA 01 / CONTEXTO
Problema

O principal desafio foi compreender como um chatbot interpreta uma interação e determina qual resposta apresentar ao usuário. Para isso, estabeleci como objetivo desenvolver uma demonstração funcional e simplificada, utilizando um conjunto de regras previamente definido, sem depender de mecanismos mais complexos de processamento de linguagem.

ETAPA 02 / SOLUÇÃO
O que eu fiz

Desenvolvi um chatbot utilizando o framework Next.js e a linguagem JavaScript. Criei uma base própria de respostas e implementei uma lógica de decisão com estruturas if e else, relacionando condições específicas às mensagens que deveriam ser apresentadas durante a interação.

ETAPA 03 / IMPLEMENTAÇÃO
Como eu fiz

A aplicação foi construída com Next.js, utilizando JavaScript para implementar o comportamento do chatbot e CSS para definir sua apresentação visual. As regras de conversação foram organizadas por meio de estruturas condicionais, permitindo associar cada situação prevista a uma resposta correspondente da base de conteúdo.

ETAPA 04 / RESULTADO
Resultado

O resultado foi um chatbot demonstrativo, com uma base de respostas criada por mim e controlada por condições if e else. O desenvolvimento proporcionou uma experiência prática na utilização de JavaScript, Next.js e CSS, além de contribuir para a compreensão de fluxos básicos de interação e lógica de programação.
